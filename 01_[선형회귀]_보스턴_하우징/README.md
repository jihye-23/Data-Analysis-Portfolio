# 저소득층 비율과 방 개수로 보스턴 주택가격을 설명할 수 있는가

## 요약 (Executive Summary)

- **데이터:** Boston Housing Dataset
- **규모:** 506개 관측치 × 14개 변수
- **분석 유형:** 지역 특성과 주택가격의 관계 분석(회귀)

> 보스턴 506개 인구조사 구역의 지역 특성과 주택 중위가격을 분석하였다. 전처리·변수 선택을 조합한 6개 회귀모형 중 **도메인 변수 제외·로그 변환·IQR 경계값 대체를 적용한 7변수 모형**을 선정하였다.
>
> 최저 로그 척도 RMSE 모형보다 **변수는 3개 적고, 오차는 2.17% 높았다.** 저소득층 비율의 표준화계수 절댓값은 평균 방 개수의 약 **4.2배**였다. 모든 지표는 **전체 자료의 적합 결과**이며, 새로운 자료의 예측 성능은 아니다.

## 프로젝트 개요 및 데이터

- **목적:** 지역 특성과 가격의 관계, 변수 선택·변환에 따른 적합도와 해석 가능성을 비교한다.
- **주요 질문:** 방 개수와 사회경제적 특성 중 무엇이 가격과 더 큰 관련성을 보이는가?
- **관측 단위:** 1970년 보스턴 광역권 인구조사 구역.
- **분석 대상:** 주택 중위가격 `MEDV` - 원자료 단위는 천 달러.
- **주요 변수:** 방 개수, 저소득층 비율, 대기오염, 고용센터 거리, 재산세율, 학생-교사 비율, 찰스강 인접 여부.
- **데이터 특징:** `MEDV` = 50인 상한 절단값 16건을 별도로 삭제하지 않았다.

## 분석 과정

1. 자료형·중복·결측치·이상치·가격 상한값을 점검하였다.
2. 분포 시각화, Spearman 상관분석, 찰스강 인접 여부에 따른 집단 비교를 수행하였다.
3. 변수 간 상관과 VIF로 정보 중복을 검토하였다.
4. 로그 변환·IQR 경계값 대체·도메인 변수 제외를 조합한 6개 회귀모형에 후진소거법을 적용하였다.
5. 로그 척도 모형 간 RMSE 격차와 변수 수를 고려해 모형을 선정하였다.
6. 잔차 가정을 진단하고, HC3 강건 표준오차와 표준화계수로 결과를 해석하였다.

## 주요 인사이트 및 분석 판단

- **`LSTAT`의 관련성이 가장 컸다** - 표준화계수 절댓값 0.589로 `RM`(0.141)의 약 **4.2배**다.
- **단변량과 다변량 결과는 달랐다** - `DIS`는 상관계수 ρ = +0.446에서 다른 변수를 통제한 회귀계수 B = −0.163으로 부호가 바뀌었다.
- **개별 상관만으로 변수를 선택하지 않았다** - `CRIM`은 단변량에서는 유의했지만, 후진소거에서는 유의하지 않아(p = .365) 제외되었다.
- **VIF와 변수의 의미를 함께 검토하였다** - VIF 기준에 따른 자동 제거는 없었으며, 도메인 판단으로 `INDUS`·`RAD`·`B`를 제외한 모형을 비교하였다.
- **오차와 간결함을 함께 고려하였다** - 최저 로그 척도 RMSE 모형보다 변수를 **10개 → 7개**로 줄였고, 오차 격차는 **2.17%**였다.

## 한계 및 후속 과제

- **데이터 범위:** 과거의 구역 단위 자료로, 개별 주택·현재 시장·다른 도시로의 일반화는 검증하지 않았다.
- **전처리:** 상한 절단에 따른 정보 손실과 이상치 대체 영향을 확인하기 위해 처리 전후 결과를 비교할 필요가 있다.
- **변수 사용:** 인종 구성 변수 `B`는 탐색에 포함했으나 최종 모형에서 제외하였다.
- **잔차 가정:** HC3는 표준오차를 보완하지만 가정 위배를 해소하지 않는다. 비선형 관계와 공간적 자기상관을 추가 검토할 필요가 있다.
- **성능 평가:** 지표는 로그 척도의 학습 자료 기준이다. 원본 가격 단위 평가와 학습/검증 분할·교차검증이 필요하다.
- **해석:** 모든 결과는 연관성이며 인과관계를 의미하지 않는다.
