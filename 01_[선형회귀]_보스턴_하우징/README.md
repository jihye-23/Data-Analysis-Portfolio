# 저소득층 비율과 방 개수로 보스턴 주택가격을 설명할 수 있는가

## 요약 (Executive Summary)

- **데이터:** Boston Housing Dataset
- **규모:** 506개 관측치 × 14개 변수
- **분석 유형:** 지역 특성과 주택가격의 관계 분석(회귀)

> 보스턴 광역권 506개 인구조사 구역의 지역 특성과 주택 중위가격의 관계를 분석하였다. 로그 변환·이상치 대체·통계적 변수 선택·도메인 판단을 조합한 6개 회귀모형을 비교하고, **도메인 판단과 로그 변환을 적용한 7변수 모형**을 최종 선정하였다.
>
> 기준선보다 변수를 4개 줄이면서 원본 가격 단위의 RMSE를 6.1% 낮췄다. 최종 모형에서는 저소득층 비율이 평균 방 개수보다 큰 표준화계수 절댓값을 보였다. 다만 아래 성능은 **전체 자료에 대한 적합 결과**이며, 새로운 자료에 대한 예측 성능은 아니다.

## 핵심 결과

| 항목           | 결과                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 최종 모형      | `log(MEDV) ~ CHAS + NOX + RM + log(DIS) + TAX + PTRATIO + log(LSTAT)` |
| 설명력         | 로그 척도 조정 R² 0.748 / 원본 척도 R² 0.771                          |
| 적합 오차      | RMSE 4.393천 달러 / MAE 3.058천 달러                                    |
| 주요 관련 변수 | `LSTAT` β = −0.597 / `RM` β = +0.133                             |
| 유의성·공선성 | 7개 변수 모두 HC3 기준 p < .005 / 최종 최대 VIF 4.21                    |
| 잔차 진단      | 선형성·정규성·등분산성 위배, DW 0.921로 독립성 관련 신호 확인         |

## 프로젝트 개요 및 데이터

- **목적:** 지역 특성과 가격의 관계를 확인하고, 변수 선택·변환에 따른 적합도와 해석 가능성을 비교한다.
- **주요 질문:** 평균 방 개수와 지역의 사회경제적 특성 중 무엇이 가격을 더 잘 설명하는가? 통계적 선택과 도메인 판단을 어떻게 함께 활용할 수 있는가?
- **규모·단위:** 506행 × 14열, 1행은 인구조사 구역 1곳이다.
- **분석 대상:** 주택 중위가격 `MEDV` - 천 달러.
- **주요 변수:** 방 개수, 저소득층 비율, 대기오염, 고용센터 거리, 재산세율, 학생-교사 비율, 찰스강 인접 여부.
- **특징:** 1970년 인구조사 기반 자료이며, 가격이 50에서 상한 절단된 16건을 유지하였다.

## 분석 과정

1. 자료형·중복·결측치·이상치와 가격 상한값을 점검하였다.
2. 분포 시각화, Spearman 상관분석, 찰스강 인접 여부에 따른 집단 비교를 수행하였다.
3. 설명변수 간 상관과 VIF로 정보 중복을 검토하였다.
4. 로그 변환·IQR 경계값 대체·도메인 기반 변수 제외를 조합한 6개 다중선형회귀모형에 후진소거법을 적용하였다.
5. 원본 가격 단위의 RMSE와 변수 수를 고려해 최종 모형을 선정하였다.
6. 잔차의 네 가지 가정을 진단하고, HC3 강건 표준오차와 표준화계수로 결과를 해석하였다.

## 주요 인사이트 및 분석 과정에서의 판단

- **간결함과 적합도를 함께 고려하였다.** 최종 모형은 최저 RMSE 모형보다 오차가 1.33% 높았지만 변수가 3개 적었다.
- **단변량과 다변량 결과를 구분하였다.** `DIS`는 단변량 상관이 양수였으나 다른 변수를 통제한 회귀계수는 음수였다. 개별 상관만으로 관계를 판단하기 어렵다.
- **VIF와 변수의 의미를 함께 검토하였다.** 도메인 판단으로 `INDUS`·`RAD`·`B`를 제외한 모형을 별도로 비교하였다.
- **분석된 특성 중 `LSTAT`의 관련성이 가장 컸다.** 이 결과는 해당 자료에서의 연관성이며, 지역 구성을 바꾸면 가격이 변한다는 인과적 결론은 아니다.

## 한계 및 후속 과제

- 과거의 구역 단위 자료이므로 현재 시장이나 개별 주택 가격에 그대로 적용할 수 없다.
- 가격 상한값으로 고가 구간의 정보가 손실되어 있다. 상한값 제외 전후 비교를 후속 과제로 남겼다.
- 인종 구성을 지수화한 `B`는 모형 탐색에는 포함되었으나 최종 모형에서는 제외하였다.
- HC3로 이분산에 대한 표준오차를 보완했지만, 이분산성 자체와 다른 가정 위배가 해소된 것은 아니다.
- DW 결과는 행 순서의 영향을 고려해야 하며, 공간적 자기상관은 추가 확인이 필요하다.
- 후속 과제로 비선형 관계 검토, 공간적 자기상관 확인, 학습·평가자료 분리와 교차검증을 제시하였다.
