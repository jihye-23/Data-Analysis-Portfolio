
# 데이터 분석 포트폴리오 | 성지혜

Python을 기반으로 데이터 전처리, 탐색적 데이터 분석(EDA), 통계 분석, 회귀분석 및 머신러닝을 수행한 데이터 분석 포트폴리오입니다.

개인적으로 진행한 분석과 데이터 분석 교육과정에서 수행한 포트폴리오용 분석 결과를 정리하고 있습니다.

---

## 주요 분석 내용

- 데이터 품질 점검 및 전처리
- 탐색적 데이터 분석(EDA)
- 통계적 가설검정
- 선형회귀 및 회귀 진단
- 머신러닝 모델링 및 성능 비교
- 데이터 시각화 및 결과 해석

---

## Tech Stack

**Language / Analysis**
Python · SQL · Pandas · NumPy · scikit-learn

**Visualization / Tools**
Matplotlib · Seaborn · Tableau · QGIS · Jupyter Notebook · GitHub
