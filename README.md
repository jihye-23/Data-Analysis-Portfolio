# 데이터 분석 포트폴리오 | 성지혜

<img src="성지혜%20프로필%20사진.jpg" alt="성지혜 프로필 사진" width="150" align="right" />

Python을 기반으로 데이터 전처리, 탐색적 데이터 분석(EDA), 통계 분석, 회귀분석 및 머신러닝을 수행한 포트폴리오입니다.

개인 분석과 데이터 분석 교육과정에서 수행한 프로젝트를 정리하고 있습니다.

**분석 목적과 전처리 판단, 주요 결과와 한계가 연결되도록 작성했습니다.**

## 주요 분석 내용

- 데이터 품질 점검 및 전처리
- 탐색적 데이터 분석(EDA) 및 시각화
- 상관분석 및 통계적 가설검정
- 선형회귀 및 잔차 진단
- 머신러닝 모델 비교·튜닝 및 과적합 진단
- 결과 해석 및 한계 정리
