# 개인 특성과 의료비 청구액의 관계 분석

## 요약 (Executive Summary)

- **데이터:** Insurance / Medical Cost Personal Datasets
- **규모:** 원본 1,338행 × 7열 → 분석 1,337행 × 7열
- **분석 유형:** 개인 특성과 의료비의 관계 분석(회귀)

> Insurance 데이터의 나이·BMI·흡연 여부 등 개인 특성과 의료비 청구액의 관계를 분석하였다. 집단 비교와 상관분석 후 기본 다중선형회귀와 의료비 로그 변환 모형을 비교하고, **원본 금액 단위의 오차가 더 낮은 4변수 기본 모형**을 선정하였다.
>
> 흡연 여부는 다른 개인 특성을 통제한 이후에도 의료비와 가장 뚜렷한 관련을 보였다. 분석 대상인 `charges`는 정기 납부 보험료가 아닌 **개인별 의료비 청구액**이다. 아래 지표는 전체 자료에 대한 적합 결과다.

## 핵심 결과

| 항목        | 결과                                                              |
| ----------- | ----------------------------------------------------------------- |
| 최종 모형   | `charges ~ age + bmi + children + smoker`                       |
| 설명력      | R² 0.7495 / 조정 R² 0.7488                                      |
| 적합 오차   | RMSE 약 6,059달러 / MAE 약 4,181달러                              |
| 흡연 여부   | 다른 조건을 통제했을 때 흡연자의 청구액이 평균 약 23,810달러 높음 |
| 지역별 차이 | Welch ANOVA p = .0535로 유의수준 .05에서 유의하지 않음            |
| 잔차 진단   | 선형성·정규성·등분산성 위배 / DW 2.088                          |

## 프로젝트 개요 및 데이터

- **목적:** 의료비 차이와 관련된 주요 특성을 확인하고, 선형회귀의 설명력과 한계를 평가한다.
- **주요 질문:** 다른 특성을 고려한 후에도 흡연 여부에 따른 차이가 유지되는가? 로그 변환이 원본 금액 단위의 적합도를 개선하는가?
- **규모:** 원본 1,338행 × 7열, 중복 1건 제거 후 1,337행 × 7열.
- **주요 변수:** 나이, 성별, BMI, 부양 자녀 수, 흡연 여부, 미국 내 거주 지역.
- **분석 대상:** 의료비 청구액 `charges` — 달러.
- **특징:** 결측치는 없으며, 일부 고액 청구액으로 인해 오른쪽 꼬리가 긴 분포를 보인다.

## 분석 과정

1. 문자열 공백·자료형·중복·결측치와 IQR 기준 이상치를 점검하였다.
2. 범주형 변수를 정리하고, BMI·의료비 이상치는 실제 관측값일 가능성을 고려해 유지하였다.
3. 분포 시각화와 Spearman 상관분석으로 수치형 변수의 관계를 확인하였다.
4. Mann–Whitney U 검정, Welch ANOVA, Games–Howell 사후검정으로 집단 차이를 확인하였다.
5. 후진소거법을 적용한 기본 회귀모형과 의료비 로그 변환 모형을 비교하였다.
6. 원본 금액 단위의 오차로 최종 모형을 선정하고, 잔차 진단과 HC3 강건 표준오차로 결과를 검토하였다.

## 주요 인사이트 및 분석 과정에서의 판단

- **고액 관측값을 일괄 삭제하지 않았다.** IQR 기준 의료비 이상치 139건은 실제 고액 의료비 집단을 반영할 가능성을 고려해 유지하였다.
- **흡연 여부의 관련성은 다중회귀에서도 유지되었다.** 표준화계수는 흡연 여부 0.794, 나이 0.299, BMI 0.162, 자녀 수 0.047 순이었다.
- **유의성과 관계의 크기를 구분하였다.** 자녀 수도 유의했으나 최종 변수 중 표준화계수는 가장 작았다.
- **로그 변환을 자동으로 채택하지 않았다.** 원본 금액 단위 RMSE가 약 8,368달러로 기본 모형보다 높아 최종 모형에서 제외하였다.
- **성별과 지역은 기본 모형에 남지 않았다.** 후진소거 결과 나이·BMI·자녀 수·흡연 여부가 최종 설명변수로 선정되었다.

## 한계 및 후속 과제

- 질환·진료 내용·의료 이용 횟수·보장 범위 등 주요 정보가 없어 의료비 차이를 충분히 설명하기 어렵다.
- 선형성·정규성·등분산성 위배가 남아 있다. HC3는 표준오차를 보완하지만 가정 위배 자체를 해결하지는 않는다.
- 학습·평가자료 분리와 교차검증을 수행하지 않아 제시된 지표는 새로운 자료의 예측 성능이 아니다.
- 후속 과제로 고액 관측값의 영향 검토, 비선형 모형 비교, 잔차 가정 개선, 교차검증과 설명변수 보완을 제시하였다.
- 결과는 관찰된 관련성이며, 실제 보험료 산정이나 인과적 판단의 근거로 해석하지 않는다.
